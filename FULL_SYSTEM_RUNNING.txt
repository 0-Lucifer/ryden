================================================================================
                      TROUBLESHOOTING
================================================================================

Q: "White screen" in browser?
A: Wait 30-60 seconds for Metro Bundler to finish
   Check console for errors
   Try pressing 'r' to reload

Q: Port already in use?
A: Another app is using the port
   Change port in Expo: npx expo start --port 8082
   Or kill the process: netstat -ano | findstr :8081

Q: Services won't connect?
A: Verify Docker is running: docker ps
   Check container status: docker logs <container-name>
   Restart Docker: docker restart <container-name>

Q: Database connection error?
A: Check PostgreSQL is running: docker exec ryden-postgres psql -U ryden
   Verify credentials match database env vars

Q: Can't see logs?
A: Run: docker-compose -f backend/docker-compose.yml logs -f
